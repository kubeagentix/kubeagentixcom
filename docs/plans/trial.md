# Pro Trial

Try all KubeAgentiX Pro features free for 14 days. No sign-up required, no credit card needed.

## What is Pro Trial?

Pro Trial gives you **full access to all Pro features** for 14 days. It's essentially Pro with a time limit and 1 cluster restriction.

| Aspect | Pro Trial | Pro |
|--------|-----------|-----|
| Duration | 14 days | Unlimited |
| Clusters | **1** | **Unlimited** |
| Features | All Pro features | All Pro features |
| Packs | All packs | All packs |
| AI Mode | BYOK | BYOK |
| Sign-up | Not required | Required |

## What's Included

During your Pro Trial, you get full access to:

### All Packs
- **Kubernetes Core**: Resource management, shell, port-forward
- **Prometheus Monitoring**: Metrics exploration, dashboards
- **Loki Logging**: Log aggregation and search
- **GitOps (ArgoCD)**: GitOps deployment management
- **Helm**: Helm chart management
- **Security (Trivy)**: Vulnerability scanning
- **Cost Analysis**: Resource optimization

### AI Features (BYOK)
- **AI Chat**: Natural language interaction with your cluster
- **Root Cause Analysis**: AI-powered incident investigation
- **Runbook Generation**: Create operational procedures automatically
- **Quick Diagnostics**: Rapid cluster health assessment
- **Cost Optimization**: AI recommendations for efficiency

### Integrations
- **Issue Tracking**: Jira, GitHub Issues, Linear
- **Alerts**: AlertManager, Grafana integration

## Trial Limitations

### 1 Cluster Limit

Pro Trial is limited to **1 cluster** to keep the evaluation focused. This lets you:
- Evaluate all features on your primary cluster
- Test AI capabilities with real workloads
- Explore all packs and integrations

Upgrade to Pro to unlock **unlimited clusters**.

### 14-Day Duration

The trial lasts exactly 14 days from first launch:
- Countdown visible in the app banner
- Email reminder sent 2-3 days before expiration
- No automatic billing - you choose to upgrade

## How Pro Trial Works

### Auto-Start (No Sign-up)

Unlike traditional trials, Pro Trial starts **automatically**:

1. Download and install KubeAgentiX
2. Launch the app
3. Pro Trial begins immediately
4. No email, no sign-up, no credit card

The trial is tracked locally using device fingerprinting (anti-abuse measure).

### Trial Banner

While in Pro Trial, you'll see a banner:

```
🚀 Pro Trial: 10 days left • 1 cluster | Upgrade to Pro for unlimited clusters →
```

As expiration approaches (≤3 days):

```
⚠️ Pro Trial: 2 days left | Upgrade to unlock unlimited clusters →
```

## Trial FAQ

### Can I extend my trial?

Standard trials are 14 days. Contact support if you need more time for enterprise evaluation.

### Do I need a credit card?

No credit card is required. Trial starts automatically.

### Can I use AI during trial?

Yes, using BYOK (Bring Your Own Key). Configure your own AI provider API key:
- Google Gemini (recommended - has free tier)
- OpenAI
- Anthropic
- Ollama (local)

### Will I be charged automatically?

No. There is no automatic billing. You must explicitly choose to upgrade.

### Can I trial again?

Trials are one per device. The system uses device fingerprinting to prevent abuse.

### What data is collected?

- Usage metrics (anonymous, for analytics)
- Feature usage (to improve the product)
- No cluster data leaves your machine
- Trial state stored locally (encrypted)

### Is my trial data synced?

No. Pro Trial does not include cloud sync. Your settings are stored locally. Cloud sync is available after upgrading.
