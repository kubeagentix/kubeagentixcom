## Detailed Plan Features

### Free

**Price**: $0 forever

**Includes**:
- 1 cluster connection
- Basic packs (Kubernetes Core, Prometheus, Loki)
- Resource browsing and navigation
- Pod shell access
- Port forwarding
- Basic log viewing
- Metrics dashboard
- Community support via GitHub

**Limitations**:
- No AI-powered features
- No advanced packs (GitOps, Helm, Security, Cost)
- No issue tracking integration
- No alert integration

---

### Pro Trial

**Price**: Free for 14 days

**Includes**:
- All Pro features unlocked
- All packs enabled
- BYOK AI mode available
- No credit card required
- Starts automatically on first launch

**Limitations**:
- 1 cluster limit (to evaluate)
- 14-day duration

**What happens after trial**:
- Reverts to Free tier if not upgraded
- All configurations remain intact
- Can upgrade anytime

---

## AI Credit Information

### Who Gets Credits?

| Plan | AI Credits | AI Mode |
|------|------------|---------|
| Free | None | N/A |
| Pro Trial | None | BYOK |
| Pro | None | BYOK |
| Pro Plus | 100/month | Managed + BYOK |
| Lifetime | None | BYOK |
| Enterprise | Custom | Managed + BYOK |

### Credit vs BYOK

**BYOK (Bring Your Own Key)**:
- Use your own AI provider API keys
- Pay providers directly
- No usage limits (depends on your API plan)
- Supported: Google Gemini, OpenAI, Anthropic, Ollama

**Managed AI (Credits)**:
- We handle the AI infrastructure
- Credits consumed per request
- Based on Gemini 2.5 Flash pricing
- Simpler setup, no API key management

## Frequently Asked Questions

### Can I change plans?

Yes, you can upgrade or downgrade at any time:
- **Upgrade**: Immediate access, prorated billing
- **Downgrade**: Changes take effect at next billing cycle

### What happens to unused credits?

- **Pro Plus**: Credits roll over for up to 2 months
- **Canceled subscriptions**: Credits remain available for 30 days

### Do credits expire?

- **Active subscriptions**: Credits roll over (up to 2 months)
- **After cancellation**: Available for 30 days

### Can I use multiple AI providers?

- **BYOK mode**: Yes, switch between Gemini, OpenAI, Anthropic, Ollama
- **Managed mode**: Uses Gemini 2.5 Flash only

### Is there a refund policy?

- **Monthly**: Cancel anytime, no refund for partial months
- **Annual**: Prorated refund within first 30 days
- **Lifetime**: 14-day money-back guarantee

### What's the difference between Pro and Lifetime?

| Aspect | Pro ($19/mo) | Lifetime ($99) |
|--------|--------------|----------------|
| Payment | Monthly | One-time |
| Duration | While subscribed | Forever |
| Total cost (1 year) | $228 | $99 |
| Total cost (2 years) | $456 | $99 |
| AI Mode | BYOK | BYOK |
| Future features | Included | Included |

**Lifetime pays for itself in 5 months!**
