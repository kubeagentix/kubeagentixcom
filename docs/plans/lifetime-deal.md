## How It Works

### 1. Purchase the Lifetime Deal

- Visit the upgrade page in Settings > Subscription
- Select "Lifetime Deal"
- Complete one-time payment
- License activates immediately

### 2. Configure Your API Keys

Go to **Settings > AI Configuration** and add your provider keys:

**For Google Gemini (Recommended)**:
1. Get API key from [Google AI Studio](https://aistudio.google.com/)
2. Paste into KubeAgentics Settings
3. Select your preferred model

**For OpenAI**:
1. Get API key from [OpenAI Platform](https://platform.openai.com/)
2. Paste into KubeAgentics Settings
3. Select your preferred model

**For Anthropic**:
1. Get API key from [Anthropic Console](https://console.anthropic.com/)
2. Paste into KubeAgentics Settings
3. Select your preferred model

**For Ollama (Local)**:
1. Install Ollama on your machine
2. Pull desired models (`ollama pull llama3`)
3. Configure local endpoint in KubeAgentics

### 3. Start Using

Once configured, all AI features work immediately:
- AI Chat
- Root Cause Analysis
- Runbook Generation
- Quick Diagnostics
- Cost Optimization

## Frequently Asked Questions

### Is this really lifetime?

Yes. As long as KubeAgentics exists, your Pro access is valid. We've structured the business to support lifetime licenses.

### What if KubeAgentics shuts down?

In the unlikely event of shutdown:
- Full source code would be released (we're already open-source)
- You'd retain full functionality
- Community could continue development

### Can I share my license?

No, licenses are single-user. Each team member needs their own license or a Team plan.

### Do I need API keys immediately?

You can purchase now and configure keys later. The license activates immediately.

### Can I switch providers?

Yes, switch providers anytime in Settings. Your license isn't tied to any specific provider.

### What if I already have a Pro subscription?

- Remaining subscription time is prorated
- Transition to Lifetime is seamless
- Any remaining credits are forfeited (BYOK doesn't use credits)

### Is Ollama really free?

Yes, Ollama runs models locally at no per-request cost. You only need sufficient hardware (GPU recommended).

### Can I upgrade to Team later?

Yes, Team licenses can be purchased separately. Lifetime license holders get a discount on Team seats.
